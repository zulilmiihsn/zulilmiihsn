## ⚡ What I Actually Build (The Real Lore)

I don't just build toy apps or follow basic tutorials. I engineer solutions that solve real operational bottlenecks, survive harsh hardware constraints, and generate actual business impact:

- 🤖 **PaddleOCR + OpenCV Ingestion (BPS Kota Malang)**: When government surveyors faced thousands of physical 17-column survey sheets, I built a 6-stage Document AI pipeline that cut manual data-entry time by 99.4% using fuzzy spatial cell mapping.
- 🦾 **Autonomous Growth & Stealth RPA**: Built a fullstack multi-account Facebook Marketplace & Groups automation platform using **Playwright Stealth**, **Groq AI copywriter agents**, **Express 5**, and an embedded SQLite database with a live operator dashboard.
- 🧃 **Offline-First POS for Low-Spec Retail Hardware**: When GoKasir was discontinued, I engineered a zero-lag SvelteKit 5 + Supabase + IndexedDB POS for **Zatiaras Juice** that runs smoothly on second-hand potato phones/tablets with offline receipt queueing and cash shift auditing.
- 🏛️ **Enterprise Cloud Archiving & Fullstack Platforms**: Shipped enterprise cloud archiving automation for **PUSJARSKPP** (Google Apps Script + CI/CD), fullstack school portals (**Sekolahku** with Supabase + Leaflet GIS), and native **Kotlin Android** apps.
- 🖥️ **Apple-Inspired Web OS**: Architected **ilmi-os**, an interactive dual-mode (macOS/iOS) web operating system with full window multitasking, draggable icons (@dnd-kit), and Zustand state management.
