## Background & Engineering Focus

Most of my work revolves around solving practical operational bottlenecks:

- **Document AI & OCR**: Built automated data extraction tools for Badan Pusat Statistik (BPS Kota Malang) to digitize complex 17-column paper survey forms using PaddleOCR and OpenCV, cutting manual form entry time by 99.4%.
- **Growth & Browser Automation**: Engineered multi-account Facebook Marketplace and Group automation systems using Playwright Stealth, Groq AI copywriters, Express 5, and SQLite.
- **Hardware-Constrained POS**: Developed an offline-first Point of Sale system for Zatiaras Juice after third-party software was discontinued. Built with SvelteKit, Supabase, and IndexedDB to ensure zero lag on older, low-spec cashier devices.
- **Cloud & Fullstack Platforms**: Shipped enterprise document archiving for PUSJARSKPP (Google Apps Script + CI/CD), fullstack school portals (Next.js + Supabase + Leaflet GIS), and native Android applications in Kotlin.
- **Web Systems Architecture**: Created `ilmi-os`, an interactive macOS/iOS web operating system simulator with window multitasking, draggable desktop grids, and Zustand state machines.

---

## Core Stack

- **AI & Automation**: Python, PaddleOCR (PP-OCRv5), OpenCV, Playwright Stealth, Groq API, n8n, Zapier, Chrome Extensions (Manifest V3)
- **Frontend**: Next.js (14/15), React, TypeScript, SvelteKit, Zustand, Tailwind CSS, Framer Motion
- **Backend & Database**: Supabase (PostgreSQL), Firebase Firestore, Express 5, SQLite (WAL mode), IndexedDB, Google Apps Script
- **Mobile**: Kotlin (Native Android)
